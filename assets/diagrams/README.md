# Figures from the Layers-and-Seams manuscript

The maintainer approved these bilingual adaptations of the revised manuscript figures:

- `layers-and-seams-{cs,en}.svg`: Figure 1, the general model.
- `czech-ndi-layers-{cs,en}.svg`: Figure 2, functions and instruments in the Czech NDI.
- `metadata-architecture-{cs,en}.svg`: Figure 3, metadata architecture.

Source: *Layers and seams of FAIR implementation in the Czech national research data infrastructure*
(in preparation), cited as `layers-and-seams-manuscript` in the guide.

Keep the original geometry, layer colours and terminology. Adaptations change fonts for web display,
translate labels, fit text within its existing box and add accessible titles and descriptions.
Retain status scope and arrow meanings. The maintainer confirmed October 2026 for the guide figures;
source-scoped catalogue examples retain their documented September observations. The figures do not establish
the status of every repository or organisation. Review both languages when updating a pair.
